# Butterfly API

Butterfly API is a lightweight developer library for **Fabric mods on Minecraft 1.21.11**.

It exists to simplify common modding tasks and reduce repeated boilerplate across projects.

## What It Provides

Butterfly API includes helpers for:

- content registration and `ModContext`
- blocks and multiblocks
- item utilities and progress bars
- custom creative tabs
- plush blocks
- entity and block-entity outlines
- client registration
- math and motion utilities
- text, font, color, and text-effect helpers
- one-time bootstrap helpers

It is designed to work alongside normal Minecraft and Fabric systems rather than replace them.

## Requirements

- Minecraft 1.21.11
- Java 21
- Fabric Loader
- Fabric API
